## Context

见 `proposal.md` 的 Why / Scope：本 change 是路线图 `docs/roadmap/P8-human-orc-melee.md §3 P8.5`（`:119-131`）的 **P8.5e「战争迷雾」**（`:129` 表行「视野 / 已探索层、小地图单位点、表现层只读」、验收「迷雾 MUST NOT 进权威状态 / 哈希 / 快照」，`godot N4-D` / `Warsmash 视野语义`）；P8.5 全量已由用户 2026-11-14 拍板必做（`:28` / `:151`），五个子系统各单独 change、串行推进、不塞回 P8.0–P8.4（`:121` / `:30`），P8.5a `p8-hero-revive`、P8.5b `p8-townhall-upgrade`、P8.5c `p8-creep-camps`、P8.5d `p8-item-shop-tp` 均已归档、本 change 是**最后一个**。`:131` 硬约束：「迷雾与掉落随机码若需进权威状态，MUST 按第 4 节走 ADR 0002 流程（状态哈希 + 快照 + `first_difference()` + determinism 26 项）；否则一律做成表现层只读派生，内核零改动」。

## Goals / Non-Goals

**Goals:**

- 在表现层新建三态迷雾网格（MASKED / FOGGED / VISIBLE）、已探索层单调累积、当前可见每帧重算，满足 R10.1；在 `derive_minimap` / `Scene` 喂入前完成可见性过滤，满足小地图单位点（T5）与敌方单位 / 建筑变化不可见（R10.1）。
- 承接 P8.5c / P8.5d 明文交接的野怪 / 商店 / 地面物品迷雾可见性，位置 / 类别走只读 `Snapshot` 查表。
- 守住 R10.5 / §0.3 T3 / ADR 0002 §5：迷雾 MUST NOT 进权威状态 / FNV-1a 状态哈希 / `SNAPSHOT_VERSION` 快照 / `first_difference()`；`w3-core` 零权威状态改动（理想零 diff）；版本保持 7 全不 bump、golden hash `0x940cb016f6630f1e` 不变、determinism 26 项不因迷雾改动。
- 联机两端各自本地派生、回放逐帧重建同一迷雾（R12.2 / R12.4），不新增 desync 面、不 bump `PROTOCOL_VERSION`。
- 零资产、仅借鉴参考项目语义、AGPLv3 只借语义禁复制代码、全合成原创 `[待核]` 常量。
- 四件套一致性：proposal 的 Scope / specs 的 `#### Scenario:` / 本文件 alternatives / tasks 步骤按同一推荐单一口径一次成文。

**Non-Goals:**

- 不新增 `w3-core` 权威状态字段 / 命令 / 事件变体、不改 `w3net.proto` / `PROTOCOL_VERSION` / `hash_gameplay_command`、不给 `first_difference()` 加 fog 字段。
- 不改 `FrozenDefinitions` / `UnitDef` / `compute_defs_hash`（否则 `defs_hash` / `content_hash` 变 → golden hash 基线必变，与「保持 7 不 bump」冲突）。
- 不扩展 `WorldView` / `EntityView` 投影字段（不新增 `def_id` / `sight_radius` / `is_flying`），走装配层 `entity_defs` + 表现层合成常量。
- 不把「1.0 范围字面一并做完」的隐身反隐 / 昼夜循环全量 / R10.3 回血 / R5.6 视野阻挡 / S3 暗夜夜间隐身特色 / R8.4 野怪睡眠**静默窄化**为已确认结论——本期最小闭环与 1.0 字面范围的张力按 Q2 由用户拍板（见「## Risks / Trade-offs」与「## 范围边界」）；范围外项按 Q3 显式登记为后续 change / P9+ 四族承接待办。
- 不做 AI 玩家清野 / 拾取（R12.7 / §0.3 T5）、R9 中立建筑交互全量、全科技树、地图编辑器 / RPG 自定义地图 / 剧情战役（N2–N4）、JASS / wtg 触发器 VM（N5）、联机底座重做（P4 已交付）、纯本地单机对局形态（N1）。
- 不改主 `openspec/specs/**` 正文（归档才合并 delta）、不改活文档 `WC3-MELEE-RULES.md`、不改 ADR 正文、不改 `crates/`（提案阶段）、不 archive / commit / push。

## Decisions

> 每个决策关联 ADR 0002、列出 alternatives considered、说明对跨平台确定性与分层依赖（SRP / OCP / LSP / DIP / ISP / LoD / CARP + 唯一状态所有者 / `w3-core` 不反向依赖上层 / 显式失败不静默降级）的影响；玩法决策声明业务规则编号与核实状态（`[已核]` / `[待核]` / `[取舍]`，`[待核]` 数值不冻结进权威定义）。

### D1 方向：纯表现层只读派生、内核零权威状态改动（R10.5 `[取舍]` / ADR 0002 §5）

**决定**：迷雾网格 / 当前可见 / 已探索层 / 雾遮罩全部驻留 `crates/w3-client/`（可选 `crates/w3-render/` 呈现），派生输入 = 只读 `WorldView`(tick/entities) + 只读 `Snapshot`(creep_camps/item_shop/defs) + 事实事件 + 装配期 `entity_defs`。`w3-core` 零权威状态改动（理想 `git diff -- crates/w3-core/` 为空）。**依据**：`WC3-MELEE-RULES.md:227` R10.5 / `:55` §0.3 T3 / `:34` §0、`0003-scope.md:90`、`P8-human-orc-melee.md:129,131`、判定 1（验收线可纯表现层只读派生达到）。**alternatives considered**：① **改内核新增权威状态（fog 网格进哈希 / 快照 / `first_difference()`）**——与 R10.5 / §0.3 T3 / `:129` 正面冲突，按 `:131` 须走 ADR 0002 全套（+ bump 8 + golden hash 重取 + ADR 复核），MUST 回用户拍板触发 §8 规格门，`vera20k` fog 进哈希正是此路线（已登记「对照差异、不借鉴」，见「## 对照差异」）；② **表现层假迷雾、无已探索层（只做圆形黑幕、不累积探索）**——降级验收，不满足 R10.1「探索后地形保留」与 `:129`「已探索层」，MUST NOT 静默采用；若用户明确拍板降级须记为被否 / 降级决策 + 已知限制、不冒充完整验收；③ 混合（部分权威 / 部分表现层）——制造两套状态口径、收益为零。**跨平台确定性影响**：权威状态字段集合 / 哈希输入 / 快照布局零变化 → 不引入新的跨平台风险；派生为纯函数（无墙钟 / 渲染帧率 / `f64` / `HashMap` 迭代顺序 / 表现层独立随机源），逐帧 checksum 比权威状态哈希不含迷雾 → 不引入新 desync 面（R12.2 / R12.4）。**分层影响**：唯一状态所有者 `RtsMatch` 不变、表现层只读不反写、`w3-core` 不反向依赖上层，符合 ADR 0002 §5 / `config.yaml` 硬红线。

### D2 版本保持 7 全不 bump、golden hash 不变（R10.5 `[取舍]` / R12.4 / ADR 0002 §6-8）

**决定**：`SNAPSHOT_VERSION` / `SIM_VERSION` / `PROTOCOL_VERSION` 全部保持 7 不 bump；`Snapshot` 结构（含 `item_shop`）、FNV-1a 哈希字段集合、`first_difference()` 字段集合不变；golden hash `0x940cb016f6630f1e`（sha256 `d6c0c944…aaa41`）逐字节不变；determinism 26 项不因迷雾改动；proto 最大 tag 45 / `reserved 14 to 32` 不变、不新增命令 / 事件变体、不触 ADR 0005 线格式。**依据**：判定 1 + `snapshot.rs:43-44,102-146` + ADR 0002 复核记录 `:109-116`（P8.5a–d 逐期 bump 与 golden hash 必变的反证）。**alternatives considered**：bump 8（按 Q4 被否——前提是新增权威状态 / 定义层内容变化；本期无此前提，bump 反而制造无意义版本契约变更、旧录像明确拒绝、golden hash 重取）；保持 7 但偷偷塞新字段进快照（否决，显式失败不静默降级、ADR 0002 §7 禁止同版本号静默错读）。**跨平台确定性影响**：golden hash 基线不变、不新增跨平台验证面；ADR 0002 复核记录「Windows / Debian 12 x86_64（v3）已验证」沿用，v4–v7 Debian 侧逐字节比对 / macOS / ARM64 / 其它 rustc 仍待验证、不声称全平台达成（Q12）。**分层影响**：不新增 `w3-net` / `w3-relay` / proto 改动，符合单一 owner 约束。

### D3 常量落点：表现层合成原创编译期常量 `[待核]`，不进 `FrozenDefinitions`（R10.1 `[已核]` / R10.2 `[待核]` / R5.6 `[已核]` / §14）

**决定**：视野半径昼 / 夜、已探索层格子分辨率、昼夜时长、视野阻挡、隐身触发 / 反隐半径、雾遮罩不透明度全为**表现层合成原创编译期整数常量 `[待核]`**（B 类），MUST NOT 进 `w3-core::FrozenDefinitions` / `UnitDef` / `compute_defs_hash`；昼夜相位 `phase = tick % (day_frames + night_frames)` 从 `WorldView.tick` 按整数帧纯派生（`creep.rs:128-131,153-154` 已有冻结常量、`creep_camps.rs:911-919` 确认睡眠本期不实现）。**依据**：判定 3 ①（`gameplay.rs:297-305` `UnitDef` 七字段无视野半径、`:356-373` `FrozenDefinitions` 无 vision 段）。**alternatives considered**：**视野半径 / 昼夜常量塞进 `w3-core::FrozenDefinitions` 却声称 golden hash 不变**——经 ADR 0002 复核记录 P8.5a–d 证实 `defs_hash` / `content_hash` 变会改 golden hash 基线、自相矛盾，MUST NOT 采用（Q6 被否备选③）；若确需进定义层须如实重取基线并 bump（回到 D1 备选 ① 的拍板）。读本机导出 SLK / MiscGame 核实真实数值——超 1.0 零资产边界（ADR 0001）、数值权威来源仅本机导出且一律不入库（`:373-384` 防误用清单）。**跨平台确定性影响**：编译期整数常量在所有平台一致；整数帧相位无 `f64` / 墙钟、跨平台逐帧一致。**分层影响**：表现层常量不反向依赖 `w3-core`、不污染权威定义、`w3-content` 原始 `f64` 坐标不进哈希 / 快照（ADR 0004）。

### D4 只读视图不扩展（R10.5 `[取舍]` / R13.6 `[取舍]` / ADR 0002 §5；Q5）

**决定**：不扩展 `WorldView` / `EntityView` 只读投影字段、不新增 `sight_radius` / `def_id` / `is_flying`，走装配层 `entity_defs`（`hud.rs:764-766`）+ 表现层合成常量。**依据**：判定 3 ④（P8.4 `runtime-entity-movability` 归档 `design.md:25-40` D1 先例：投影**已有权威字段**属「只读视图扩展、零权威状态改动」但仍须经人拍板；投影**当前不存在的字段**属新增权威 / 定义层字段 → 改内核、与 R10.5 冲突；且撞 `runtime-entity-model-binding/spec.md:12,37` 的 `EntityView` 无 `def_id` 已知限制，`entity_defs` 装配期关联只覆盖 frame-0 实体）。**alternatives considered**：扩展 `EntityView` 暴露 `DefId`（否决，需把 `DefId` 存进 `UnitState` = 新增权威状态，P8.4 D1 备选 3 已否）；扩展视图暴露 `sight_radius` / `is_flying`（否决，当前无此权威 / 定义层字段、须改内核 + 触发 R10.5 冲突 + Q1 重走规格门）；扩展只读视图投影 `UnitState.speed` 之类已有字段（本期无必要、且按 P8.4 先例仍须拍板）。**跨平台确定性影响**：视图结构不变 → `read_view()` / `compute_state_hash()` 字节不变。**分层影响**：唯一状态所有者、只读视图 DIP / ISP 边界不变。

### D5 已探索层为表现层本地跨帧累积状态、联机 / 回放一致（R10.1 `[已核]` / R12.2 `[取舍]` / R12.4 `[取舍]` / R13.6 `[取舍]`）

**决定**：已探索层（三态网格）是**表现层本地**跨帧累积状态、每个本地视角一份；派生是纯函数 `f(同一权威状态序列, 本地视角, 冻结常量)`。联机两端逐帧相同权威状态序列 → 各自视角已探索层本就不该相同（`vera20k@305ea3a75 docs/Networking.md:490` every House keeps its own fog）→ 不是 desync；逐帧 checksum 比权威状态哈希不含迷雾 → 不引入新 desync 面。回放：R12.4 录像含 `defs_hash` / `content_hash` / 命令序列 / 帧号 → 逐帧重建同一序列 + 同一冻结常量 + 同一视角 → 同一迷雾；迷雾不进快照、重放按帧重新累积。**依据**：判定 2（`WC3-MELEE-RULES.md:301` R13.4 编队 / 选中集合 / 命令队列表现层只读、`:286` R13.3 子菜单状态、`:315` R13.6、`rts-command-hud/spec.md:59,64`、`playable-client/spec.md:45,50`、`hud.rs:776-781` `faction` / `faction_overlay` 表现层本地只读状态、`rts_kernel_cs/docs/FRAMEWORK.md:29`「派生缓存恢复后重建」）。**alternatives considered**：把 fog 网格作为权威状态随快照保存（否决，R10.5 / 对照差异）；重连 / 中途加入从当前帧起算的降级契约（Q7 待拍板，须显式登记为降级、不静默采用）；多视角观战（R12.5 `[待核]`）一致性契约 Q7 待拍板。**跨平台确定性影响**：派生缓存不进快照、恢复时重建，权威状态跨平台契约零变化；派生纯函数无平台相关随机源。**分层影响**：表现层持有只读派生缓存、不反写、单一状态所有者不变（`rts_kernel_cs/docs/MOVEMENT.md:109-113` 只读视图 detached/owned/不写回先例）。

### D6 HUD 只读派生与 P8.5c / P8.5d 交接承接（R10.1 `[已核]` / R10.5 `[取舍]` / R8.1 / R9.1）

**决定**：在 `HudModel` 新增迷雾只读投影子模型（与既有 `revive` / `town_hall` / `creep` / `item_shop` 同构、`derive(snapshot, events)` 范式），把 `Snapshot.creep_camps` / `Snapshot.item_shop` / `WorldView.entities` 的野怪 / 商店 / 地面物品 / 单位位置按「当前可见格」过滤后再喂 `MinimapModel.points` 与 `Scene`；地面物品不在 `read_view()` 内（`creep.rs:34-38`）MUST 走只读 `Snapshot`；过滤全在表现层、不反写、不进哈希 / 快照 / `first_difference()`。`derive_minimap` **在把单位点喂给 `MinimapModel` 之前做可见性过滤**、「在场性」（`EntityView.alive`）与「可见性」（迷雾派生）分两层、遮罩独立于底图与权威状态（参考对照结论 R2）。**依据**：判定 6 + `hud.rs:737-751,791-808`、`snapshot.rs:139,145`、`sim_match.rs:233-243`。**alternatives considered**：在 `MinimapModel` / egui 绘制侧扫描世界判断可见性（否决，违反「共享显示层不扫描世界、不访问地图文档」，参考对照结论 R2 明确要求适配层传入标记前完成过滤）；只过滤 `WorldView.entities` 不管地面物品 / 商店（否决，漏掉 P8.5c / P8.5d 交接、`creep.rs:34-38`）；把过滤结果写回权威状态（否决，R10.5）。**跨平台确定性影响**：只读派生不改 `compute_state_hash()` / `capture_snapshot()` 字节、稳定顺序无随机源。**分层影响**：`HudModel` 只消费只读数据、`hud.rs:1-14` 结构上无法反写，符合 SRP / LoD。

### D7 determinism 不因迷雾改动、反向验证形态①（R12.4 `[取舍]` / ADR 0002 §8 / `CODEBUDDY.md §5`；Q9）

### 三、核心判定 1–6（design.md alternatives 必须据此）

- **判定 1（验收线可纯表现层只读派生达到）**：逐项——视野范围（己方 `EntityView.x/y/owner/alive` + 表现层合成冻结半径 + `WorldView.tick` 昼夜；圆形揭示网格）、已探索层累积（每帧当前可见并集叠加到**表现层本地**三态网格 MASKED→FOGGED/VISIBLE）、敌方变化不可见（`MinimapModel.points` + `Scene` 动态实例喂入前按格状态过滤 / 冻结上一已知态）、小地图单位点（现成 `derive_minimap` 加可见性过滤）、地形 / 已探索遮罩（只读 `MinimapBackdrop` / `build_vertices` 之上叠加表现层雾遮罩）。**全部派生输入可从只读 `Snapshot` / `WorldView` / `EntityView` / 事实事件取得，无需新增权威状态**；野怪 / 商店 / 地面物品走只读 `Snapshot.creep_camps` / `item_shop` 查表（`hud.rs:737-751` 既有四投影子模型同构）。
- **判定 2（已探索层是跨帧累积状态——表现层本地允许 + 联机 / 回放一致）**：先例 `WC3-MELEE-RULES.md:301` R13.4（编队 / 选中集合 / 命令队列表现层只读）、`:286` R13.3（子菜单状态）、`:315` R13.6、`rts-command-hud/spec.md:59,64`、`playable-client/spec.md:45,50`、`hud.rs:776-781`（`faction` / `faction_overlay` 表现层本地只读状态）、`rts_kernel_cs/FRAMEWORK.md:29`「派生缓存恢复后重建」（R7）。联机：派生是纯函数 `f(同一权威状态序列, 本地视角, 冻结常量)`，两端逐帧相同序列 → 各自视角已探索层本就不该相同（`vera20k@305ea3a75 docs/Networking.md:490`）→ 不是 desync；逐帧 checksum 比权威状态哈希不含迷雾 → 不引入新 desync 面。回放：R12.4 录像含 `defs_hash` / `content_hash` / 命令序列 / 帧号 → 逐帧重建同一序列 + 同一冻结常量 + 同一视角 → 同一迷雾；迷雾不进快照、重放按帧重新累积。
- **判定 3（视野半径 / 昼夜 / 隐身输入 + 「扩展只读视图」边界，规格门 Q5 / Q6）**：① 视野半径当前无任何定义层字段（`gameplay.rs:297-305`、`:356-373`）→ 二选一：**(推荐) 表现层合成原创编译期常量 `[待核]`（不进 `FrozenDefinitions` / `defs_hash` → 内核零改动、哈希零冲击、golden hash 不变）** vs 加进 `w3-core::FrozenDefinitions` / `UnitDef`（定义层内容变化 → `defs_hash` / `content_hash` 变 → **改变 golden hash 基线**，与「保持 7 不 bump」冲突，须拍板）。② 昼夜相位 `phase = tick % (day_frames+night_frames)` 纯整数派生、无需权威状态（`creep.rs:115-116` 已承接「睡眠行为本期不实现」）。③ 隐身（R10.4）若仅是「不绘制 / 不显示小地图点」→ 表现层可见性过滤、不触及权威状态；若做到「隐身单位不可被选为目标」（Warsmash `isVisible` / `isDetecting` 喂目标判定）→ 触及权威状态、须新增隐身权威字段 → 哈希 / 快照 / bump，按 R10.5 应排除 / 范围外。④ **扩展 `WorldView` / `EntityView` 只读投影字段算不算改内核**：按 P8.4 D1 先例，投影**已有权威字段**属「只读视图扩展、内核零权威状态改动」但仍须经人拍板 + 规格门；投影**当前不存在的字段**（`def_id` / `sight_radius` / `is_flying`）属「新增权威 / 定义层字段 → 改内核、与 R10.5 冲突」；且撞 `runtime-entity-model-binding/spec.md:12,37` 的 `EntityView` 无 `def_id` 已知限制（`entity_defs` 装配期关联只覆盖 frame-0 实体）。**推荐不扩展视图、走装配层 `entity_defs` + 表现层合成常量**。这是规格门 Q5 / Q6，不得静默选择。
- **判定 4（与 vera20k fog 进哈希的张力，如实登记不抹平）**：见 R5 与「## 对照差异」。**本项目不借鉴 fog 进哈希 / 快照 / `first_difference()`**，根因 vera20k 是 RA2 全状态哈希复刻且 fog 参与玩法目标判定，本项目用户已拍板迷雾为呈现层派生（R10.5）。
- **判定 5（隐身反隐 / 昼夜 / 暗夜特色 / 视野阻挡是否本期全做——参考项目给不了范围答案，规格门 Q2）**：业务规则内部有范围张力：`WC3-MELEE-RULES.md:27` S3 / `:34` §0 / `:54` §0.3 T2 字面「暗夜夜间隐身 / 昼夜 / 隐身反隐随迷雾纳入一并做完」，但 `P8-human-orc-melee.md:129` P8.5e 验收线只列「视野 / 已探索层 / 小地图单位点、表现层只读」、`creep_camps.rs:911-919` 明确「昼夜睡眠本期不实现」。R10.2 / R10.3 / R10.4 分列、`R10.3 回血` / `R8.4 野怪睡眠` 若要进权威状态按 `:131` 会触发 ADR 0002 全套、与本期方向冲突。**不臆造范围**——Q2 由用户拍板、MUST NOT 静默窄化已拍板的 1.0 范围。
- **判定 6（P8.5c / d 遗留承接）**：`creep-camps/spec.md:136,143-146,174` + `item-shop-town-portal/spec.md:195-198` 措辞逐字核实（本会话 Read 核对）；本期在 `HudModel` 新增迷雾只读投影子模型（与既有 `revive` / `town_hall` / `creep` / `item_shop` 同构、`derive(snapshot, events)` 范式），把 `Snapshot.creep_camps` / `item_shop` / `WorldView.entities` 的实体 / 地面物品 / 商店位置按「当前可见格」过滤后再喂 `MinimapModel.points` 与 `Scene`；过滤全在表现层、不反写、不进哈希 / 快照 / `first_difference()`；地面物品不在 `read_view()` 内须走只读 `Snapshot`。

## 对照差异

> **显著登记（不抹平）**：`vera20k`（T1 / R5）把 fog 当**每 House 一份、进状态哈希、进 `first_difference()` 差异诊断**的权威状态（`vera20k@305ea3a75 src/sim/world/world_hash.rs:4,687-688,589-591,1488-1497,326-327`，`docs/Networking.md@305ea3a75:490`）；`WarsmashModEngine`（T4 / R3）把 fog 网格放在**模拟层**（每玩家持有、`CSimulation.java:497-507` `updateFogOfWar()` 每帧跑）。**本项目 R10.5（`WC3-MELEE-RULES.md:227`）/ §0.3 T3（`:55`）/ §0（`:34`）/ `0003-scope.md:90` / `P8-human-orc-melee.md:129-131` 正面取舍相反**：迷雾 MUST 为表现层只读派生、`w3-core` 零改动、版本保持 7 不 bump、golden hash 不变、`first_difference()` 不加 fog 字段。根因：vera20k 是 RA2 全状态哈希复刻且 fog 参与玩法目标判定；Warsmash 是 Java / LibGDX 模拟器把 fog 纳入模拟层；本项目是 WC3 Melee 且**用户 2026-11-14 已拍板迷雾为呈现层派生**。故本项目**仅借 R5 的「每玩家 / 视角各自一份」语义与「逐帧状态哈希保护派生输入」思路、仅借 R3 的「三态 / 累积 / 揭示」语义**，明确不借鉴 fog 进哈希 / 快照 / `first_difference()` / 模拟层 fog 网格。此张力由 `critic` 清单第 12 项复核，MUST NOT 借「参考项目如此」把 fog 带进权威状态（判定 4）。
