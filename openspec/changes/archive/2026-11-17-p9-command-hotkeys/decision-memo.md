# 决策纪要 — `p9-command-hotkeys`

> 取料纪律：基于仓库 artifacts、只读参考项目对照报告与用户 2026-11-16 本会话拍板回填；「拍板」项须有明确记载，找不到的一律进「待确认项」，**不把 AI 事后归纳写成「用户已确认」**。
> 合规边界：纯文档，不进 FNV-1a 状态哈希、不进 `SNAPSHOT_VERSION`（当前 3）快照、不含任何资产或本机绝对路径（ADR 0001 / ADR 0002 / `CODEBUDDY.md` §6）。
> 本 change 承接已归档 `2026-11-16-p8-human-faction`（人族六类新 `DefId`）与 `2026-11-16-runtime-entity-movability`（R1.4 分层判据），落实 1.0 范围 S1 / S3 / S4 的**经典操作层**（`WC3-MELEE-RULES.md` §0.1 操作快捷键口径 / §13 `R13`）。规格门已由用户 2026-11-16 本会话指令 + `AskUserQuestion` 方向拍板批准（与 P8.1 / `runtime-entity-movability` 先例一致）。只读 `reference-researcher` 已按 `UPSTREAM.md` 矩阵 T2 / T4 / T5（R12.2 旁证 T1 / T6）出对照报告，锚由 `spec-steward` 逐条打开复核，见 `design.md`「## 参考项目对照」。
> **锚写法**：本轮 `crates/w3-client/` 会被 owner 改动，四件套与本纪要的**本项目代码锚一律「文件路径 + 函数名 / 符号名」、不写 `:NN` 行号**（P8.1 行号漂移返工教训）；对未改动文件用章节号 / 规则编号 / 矩阵条目；参考项目为只读固定提交、其 `file:line` 锚不漂移、按对照报告原样保留。
