# ADR 0004：冻结坐标与定点单位契约（P2 竖切）

- **状态**：Accepted
- **日期**：2026-11-08
- **相关**：[ADR 0002](0002-determinism.md)、[ADR 0003](0003-scope.md)；`crates/w3-app/`、`crates/w3-core/`
- **实现对应**：OpenSpec change `p2-simulation-vertical-slice`
- **规范引用**：`deterministic-simulation` / `pathfinding` / `unit-orders` 的 P2 delta requirements

## 背景（Context）

P1 的 `w3-content` 把上游 `godot_warcraft3` 导出的地图读成中立结构，其中坐标是原始 `f64` 世界单位（见 `crates/w3-content/src/lib.rs` 的确定性边界说明）。P2 要打通「内容数据进入模拟」，但 [ADR 0002](0002-determinism.md) 规定：`f32` / `f64` 不得进入权威状态、快照或状态哈希；`w3-core` 保持零依赖；超越函数若引入必须是纯 Rust、跨平台一致的实现。

于是有两个必须先冻结的边界问题：

1. **转换本身必须确定**：若用 `v * 65536.0` 再 `.round()` 把 `f64` 转成定点，这个 `f64` 乘法发生在「进入权威状态之前」，其结果依赖浮点运算实现（FMA、扩展精度、库版本），与「相同输入逐帧一致」的目标冲突。而上游 JSON 的 `f64` 位模式（IEEE 754 binary64）本身是确定的。
2. **模拟内不能出现超越函数**：`rts_kernel_cs` 的转向 / 坡度语义用 `atan2` / `sqrt` / `Math.Tau`（`MotionRules.cs`）。直接移植会违反 ADR 0002 的零依赖与跨平台约束。`design.md` 因此定为「语义移植而非代码移植」。

本 ADR 冻结坐标缩放 / 舍入 / 单位，以及为规避超越函数而采用的角度与距离表示。只回答「为什么这样决定」，系统行为由 OpenSpec spec 描述。

## 决策（Decision）

### 1. 坐标单位与缩放

- 上游 `f64` 世界坐标与 `SimFixed` **1:1 对应**：`SimFixed::raw = round(value × 2^16)`，即 1 世界单位 = `SCALE = 65536` raw。不在模拟内做 `tileSize` / 瓦片数换算。
- `tileSize`（`terrain-heightfield.json`）只用于 app 层换算成导航格距 `cell_size`（`SimFixed`，世界单位/格）并注入静态世界；`centerOffset` 换算成 `StaticWorld.origin`（地图左下角世界坐标）。`world_to_cell` 先减原点再按 `cell_size` 做整数 floor 换算。该换算发生在冻结边界，不进入逐帧模拟。
- 单位 `f64` 世界坐标**原样 1:1 冻结、不平移**：权威状态保留真实世界坐标（含负坐标），由 `origin` 承担地图几何。否决「在 app 层把坐标平移到非负网格」——那会改变世界坐标语义，也与上一条冲突。
- 拒绝「运行时隐式转换」：所有 `f64 → SimFixed` 必须经过 `w3-app::freeze` 显式完成，转换结果才是可注入的冻结输入。

### 2. 舍入规则

- **round half away from zero**（四舍五入、.5 远离零）：对正数 `floor(x + 1/2)`，对负数取相反数后同样处理再取负。对称、无平台歧义、与 Rust 整数除法向零截断的语义配套。
- 转换拒绝 `NaN` / `±Inf` 与超出 `i64` 的值，显式返回错误而非静默截断。
- 精度为 1/65536 世界单位（约 1.5e-5），对 ±8192 量级的地图坐标与逐帧移动足够；由此引入的量化误差是可接受的确定性残差，不声称与原作逐位等价。

### 3. 转换实现：纯整数 IEEE-754 位分解

- `freeze_f64` 用 `f64::to_bits()` 取出符号位、11 位指数、52 位尾数，以 `i128` 计算 `value × 2^16` 的精确整数 / 半整数，再按第 2 条舍入到 `i64`。
- 全程只做整数运算（位操作 + `i128` 移位 / 加减），不执行任何 `f64` 算术，也不调用宿主数学库。normal / subnormal / 零分别处理；指数过大直接判溢出。
- 这样「相同 JSON 文本 → 相同 f64 位模式 → 相同 raw」在任何平台一致，且 `f64` 始终停留在冻结边界之外。

### 4. 范围核算（Q47.16 可行性）

- `SimFixed` 是 `i64` 上的 Q47.16：整数部分 47 位，约 ±1.4e14 世界单位。
- Echo Isles 量级：地图坐标约 ±8192 → raw 约 ±5.4e8；高度场顶点 129×97、格距由 `tileSize` 导出，量级相同。
- 乘法中间量：`checked_mul` 用 `i128`，`(8192 × 2^16)^2 ≈ 2.9e17`，远小于 `i128::MAX ≈ 1.7e38`；`checked_div` 的分子 `raw × 2^16 ≈ 3.5e13`。坡度 / 转向 / 距离积分在该量级不溢出。
- 结论：**P2 规模（±8192 坐标、300 单位）无需更换 Q 格式**；溢出仍由 `FixedError` 显式报错。更大坐标或规模按 ADR 0002 复核点重新评估。

### 5. 朝向：离散角度单位，避免弧度与三角函数

- 朝向为权威状态，类型 `Angle(i64)`：一整圈 = `ANGLE_SCALE = 2^16` 单位（16 位角分辨率，约 0.0055°），归一化到 `[-2^15, 2^15)`。
- 转向速率按「角度单位 / 帧」的整数增量；角度差用整数归一化后相减，不出现 `π` / `sin` / `cos` / `atan2`。
- 转向速度倍率沿用 `rts_kernel_cs` 的 25° / 140° 阈值与 smoothstep 曲线，但把角度阈值换算成 `Angle` 单位，用 `SimFixed` 整数多项式 `t²(3−2t)` 计算，最低倍率 0.12 以 `SimFixed` 表示。
- 移动方向用「目标角对应的离散单位向量」或整数向量归一化推进，位置仍以 `SimFixed` 逐帧积分，不由表现朝向反算。

### 6. 距离与坡度：整数 isqrt 与斜率，避免 libm

- 平面距离用纯整数 `isqrt(dx² + dy²)`（Newton 迭代、`i128` 中间量），是跨平台一致的整数算法，不是浮点超越函数。
- 坡度不用 `atan2`，改用斜率 `|rise| / distance`（`SimFixed::checked_div`），按 30° 封顶换算成 0..1 进度，再线性映射到上坡最低 0.6 / 下坡最低 0.85；等高线不降速。倍率进入状态哈希。
- 八方向寻路代价用整数：直线 1000、斜线 1414（√2 的保守近似），octile 启发式 `1000·max + 414·min` 保持可采纳；不引入 `double` 代价或优先队列的浮点比较。

### 7. 静态地图身份

- 注入的 `StaticWorld` 携带 `identity: u64` = FNV-1a over 显式小端编码的「宽 / 高 / 格距 raw / 行优先阻挡字节 / 高度场 raw」。
- 地图本身不嵌入快照；`restore_snapshot` 校验期望身份，不一致明确拒绝（对应 `pathfinding` 的「导航快照校验静态地图身份」requirement）。

## 备选方案（Alternatives considered）

| 方案 | 结论 | 理由 |
|---|---|---|
| `f64` 乘法 + `.round()` 转换 | 否决 | 转换发生在冻结边界却依赖浮点运算，跨平台一致性无保证；与 ADR 0002 精神冲突。 |
| 把 `f64` 直接存进权威状态、逐帧再算 | 否决 | 直接违反 ADR 0002 禁止浮点进权威状态 / 哈希 / 快照。 |
| 引入 `libm` 的 `sqrt` / `atan2` 做纯 Rust 超越函数 | 暂缓 | ADR 0002 允许纯 Rust 实现，但 `w3-core` 零依赖且竖切不需要真实角度；离散角度 + 整数 isqrt 足够，避免提前引入数值依赖。 |
| 改用弧度 `SimFixed` + 查表三角函数 | 否决 | 查表精度 / 插值本身引入误差与更大状态，收益不明显。 |
| 换 Q 格式（如 Q31.32）以容纳更大坐标 | 暂缓 | 范围核算显示 Q47.16 在 P2 规模充裕；按 ADR 0002 复核点，出现真实溢出再评估。 |
| 在内核内读取文件 / 直接依赖 `w3-content` | 否决 | 违反 ADR 0002 状态所有权与 `design.md` 的 app 层注入决策。 |

## 后果（Consequences）

**正面**：转换链路逐位可复现；模拟内零浮点、零超越函数、零外部依赖；范围经核算安全；静态地图身份可校验；与 ADR 0002 的定点 / 整数帧 / 哈希契约一致。

**负面 / 需明确接受**：

- 坐标量化到 1/65536 世界单位、角度量化到 16 位、斜线代价 1414/1000 近似 √2，均引入与原作的**确定性残差**，不声称语义完全等价（与 `design.md` 风险项一致）。
- `freeze_f64` 需自行处理 IEEE-754 边界（subnormal、NaN、Inf、溢出），代码复杂度高于一次 `f64` 乘法，须用边界测试约束。
- 整数 `isqrt` 与离散角度是本项目自定义契约，表现层若需弧度 / 向量须在视图边界转换，不得反写。
- 跨平台确定性仍**仅在 Windows / rustc 1.91 实跑**；本 ADR 只消除浮点与超越函数这一层不确定性，不等于 Linux / macOS 已验证（沿用 ADR 0002）。

## 复核点

引入浮点或超越函数、更换 Q 格式、提升规模目标（见 ADR 0003）、上游导出 schema 的 `tileSize` / 坐标单位变化、在非 Windows 平台首次实跑、需要与原作逐位对齐移动轨迹。
