## Why

`p17-melee-mechanism-alignment` 按「最小可验收闭环」收尾时把六组机制性结论顺延到 p18（见其 `decision-memo.md`「已知限制」/「apply 代码门复核」R1–R7）：三类机制（建筑击杀是否给经验的布尔开关、召唤物击杀经验折减因子、按英雄等级分档递减的经验因子查表）只有编译期合成占位、未接入结算路径；R6.3 买活「半血无蓝」未实现（`crates/w3-core/src/gameplay.rs:43`）；R6.1 英雄经验阈值分档表、R5.3 攻击类型 × 护甲类型克制倍率矩阵、R7.4 物品 / 单位回购价公式、R8.5 野怪三级 leash（归巢）判据全部未完成。同时 p17 代码门把 R1 / R2 / R4 / R5 / R6 / R7 六项成文与测试订正交 p18。这些机制全量落地会改变 `w3-core` 权威状态字段集合，必须按 [ADR 0002](../../docs/decisions/0002-determinism.md) 四处同步 + bump 全套 + golden hash 重取 + 反向验证，并连带 [ADR 0005](../../docs/decisions/0005-protobuf-payload.md) 的 `PROTOCOL_VERSION` / proto 只追加 tag / relay 版本拒绝 / canonical 契约。业务规则需求源为 `docs/references/WC3-MELEE-RULES.md` 的 **R5.3**（`:157`）/ **R6.1**（`:167`）/ **R6.3**（`:169`）/ **R6.5**（`:172`）/ **R7.4**（`:182`）/ **R8.5**（`:194`）；**R3.2 / R3.3**（`:133/:135`）upkeep 仅作 L2 反编译人工确认项登记、不写成 apply 任务。全部落在 1.0 范围 **S1（联机对战）/ S3（四族英雄）/ S4（道具）/ S5（野怪）/ S6（中立建筑）**（`:23-30`）之内，**明确不做 N1–N6**（`:42-49`：纯本地单机对局形态 / 地图编辑器 / RPG 自定义地图 / 剧情战役 / JASS · wtg VM · 官方战网 · Mod API / 任何暴雪资产入库）。`[待核]` 口径以附录「核实约定」（`:353`）为准，不静默改规则文档正文（§14 第 2 条）。

## Impact

- **确定性契约（ADR 0002）**：机制全量落地可能改变 `w3-core` 权威状态字段集合（R6.1 阈值分档表 / R5.3 克制矩阵等），新增权威状态 MUST 同时进入 FNV-1a 状态哈希与由 `SNAPSHOT_VERSION` 定义的快照（成文期当前 9、apply 阶段 bump 10），并同步 `compute_state_hash` / `first_difference` / `capture_snapshot` / `restore_snapshot` 四处；golden hash 按新实现如实重取、旧 v9 明确拒绝；反向验证（改坏验红）+ `cargo test -p w3-core --test determinism` 重跑为硬门禁。证据台账 / `[待核]` 数值 MUST NOT 进权威状态 / 状态哈希 / 快照 / golden hash / determinism / CI。
- **资产 / 法律边界（ADR 0001 / 0003 / 0004）**：零暴雪资产、零 MPQ 派生 JSON / PNG / GLB / 音效入库；数值不冻结原版真值、不写本机绝对路径 / 原版字段名 / rawcode / 技能名进权威定义；五个只读参考项目不变、`WarsmashModEngine`（AGPLv3）只借 JASS / 玩法语义、禁复制代码、不引 Java / LibGDX；`ConcordRTS`（GPL-3.0-only）对 T4 玩法语义 MUST NOT 参考；仓库外一手明文证据只作机制锚、不进门禁、不入库、不分发。
- **参考矩阵命中（`docs/references/UPSTREAM.md:104-114`）**：T1（主：机制落 `w3-core` + 四处同步 + bump + golden hash 重取）、T4（主：R6.1/R6.3/R6.5/R5.3/R7.4/R8.5 玩法语义）、T6（确定命中：p18 独占 bump 已把 `PROTOCOL_VERSION` 9→10 + proto 只追加 tag + relay 版本拒绝 + canonical 定为确定范围，与是否新增 `GameplayCommandKind` 无关）、T2（边缘：R8.5 三级 leash 独立行为结构）、T7（可选交叉、仅 T1 方法论）、T3（不命中：不冻结真值、不读本机导出表）、T5（不命中）。`reference-researcher` 已按五个固定提交实地核实、逐条落 `design.md`「## 参考项目对照」G1–G8，缺口如实登记回到用户拍板，待 `critic` 清单第 12 项复核。
