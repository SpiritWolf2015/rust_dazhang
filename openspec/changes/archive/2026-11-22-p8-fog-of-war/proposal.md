# Proposal

## Why

落实路线图 `docs/roadmap/P8-human-orc-melee.md:129` 的 **P8.5e「战争迷雾」**（P8.5 五子系统最后一个，验收「迷雾 MUST NOT 进权威状态 / 哈希 / 快照」）：P8.5 全量由用户 2026-11-14 拍板必做、五子系统串行（`:119-131`），P8.5a–d 已归档。`WC3-MELEE-RULES.md` §0.3 T2 / T3（`:54-55`）、§0 迷雾口径（`:34`）与 R10.5（`:227`）已拍板「迷雾 / 视野 MUST 为表现层只读派生、不进权威状态 / 哈希 / 快照」，ADR 0003 修订记录（`0003-scope.md:86-92`）同步记「`w3-core` 零改动、不新增权威状态字段、`SNAPSHOT_VERSION` 不变」。P8.5c 明文把「迷雾下野怪可见性」留 P8.5e（`creep-camps/spec.md:136,143-146,174`），P8.5d 把「迷雾下商店 / 地面物品可见性」显式登记为范围外承接（`item-shop-town-portal/spec.md:195-198`）。现状表现层无任何 fog / vision / visibility / explored 实现（全库 Grep 仅 `w3-render/src/gpu/mod.rs:465,475,485` 的 `wgpu::ShaderStages` 标志与 `creep.rs:128-131` 昼夜冻结常量），而已暴露 tick 的 `WorldView`、只读 `Snapshot`（`creep_camps` / `item_shop`）、`derive_minimap` 提供全部派生输入。规则依据 R10.1–R10.5 / R5.6 / R12.2 / R12.4 / R13.6 / R8.4 / §0 S1–S3 / §14；ADR 0001 / 0002 §5 / 0003 / 0004 / 0005 §4。**方向 / 范围 / 版本 / 边界尚未拍板，按规格门 Q1–Qn 一次拍板，不拿沉默当授权**。

## What Changes

- **推荐方向：纯表现层只读派生、`w3-core` 零权威状态改动（理想零 diff）**，待规格门 Q1 拍板。在 `crates/w3-client/` 新建表现层本地三态迷雾网格（未探索 MASKED / 已探索 FOGGED / 当前可见 VISIBLE），当前可见每帧重算、已探索层单调累积；在 `derive_minimap` 与 `Scene` 动态实例喂入 `MinimapModel.points` / 渲染顶点之前按格状态做可见性过滤；可选在 `crates/w3-render/` 叠加雾遮罩呈现。派生输入 = 只读 `WorldView`（tick / entities）+ 只读 `Snapshot`（`creep_camps` / `item_shop` / `defs`）+ 事实事件 + 装配期 `entity_defs`。全部派生 MUST NOT 进权威状态 / FNV-1a 状态哈希 / 由 `SNAPSHOT_VERSION` 定义的快照 / `first_difference()`（R10.5 / ADR 0002 §5）。
- **版本与确定性基线保持不动（按 Q4 推荐，待规格门拍板）**：`SNAPSHOT_VERSION` / `SIM_VERSION` / `PROTOCOL_VERSION` 全部保持 **7** 不 bump；`Snapshot` 结构（含 `item_shop`）、FNV-1a 哈希字段集合、`first_difference()` 字段集合不变；golden hash `0x940cb016f6630f1e`（sha256 `d6c0c944…aaa41`）不变；determinism 26 项不因迷雾改动；proto 最大 tag 45 / `reserved 14 to 32` 不变、不新增命令或事件变体、不触 ADR 0005 线格式。**本期方向与 P8.5a–d 相反（后者逐期 bump 3→7 / 重取 golden hash），MUST NOT 沿用其口径**。
- **常量落点（按 Q6 推荐，待规格门拍板）**：视野半径昼 / 夜、已探索层格子分辨率、昼夜时长、视野阻挡、雾遮罩不透明度等全为**表现层合成原创编译期常量 `[待核]`**，MUST NOT 进 `w3-core::FrozenDefinitions` / `UnitDef` / `compute_defs_hash`（否则 `defs_hash` / `content_hash` 变 → golden hash 基线必变、与「保持 7 不 bump」自相矛盾）。昼夜相位从 `WorldView.tick` 按整数帧纯派生（`creep.rs:128-131,153-154` 已有 `day_frames` / `night_frames` 冻结常量）。
- **只读视图扩展边界（按 Q5 推荐，待规格门拍板）**：不扩展 `WorldView` / `EntityView` 只读投影字段；不新增 `sight_radius` / `def_id` / `is_flying` 等当前不存在的字段。走装配层 `entity_defs`（`hud.rs:764-766`）+ 表现层合成常量。对照 P8.4 `runtime-entity-movability` D1「只读暴露 speed」先例（投影已有权威字段仍须拍板）与 `runtime-entity-model-binding/spec.md:12,37` 的 `EntityView` 无 `def_id` 已知限制。
- **P8.5c / P8.5d 明文交接承接**：在 `HudModel` 新增迷雾只读投影子模型（与既有 `revive` / `town_hall` / `creep` / `item_shop` 同构、`derive(snapshot, events)` 范式），把 `Snapshot.creep_camps` / `Snapshot.item_shop` 与 `WorldView.entities` 的野怪 / 商店 / 地面物品 / 单位位置按「当前可见格」过滤后再喂 `MinimapModel.points` 与 `Scene`；地面物品不在 `read_view()` 实体集合（`creep.rs:34-38`），MUST 走只读 `Snapshot`，不能只靠 `WorldView.entities`。过滤全在表现层、不反写、不进哈希 / 快照 / `first_difference()`。
- **范围边界（按 Q2 / Q3 推荐，待规格门拍板）**：本期最小闭环 = 视野 / 已探索层 / 小地图单位点 / 敌方变化不可见 / 只读派生；隐身反隐（R10.4）、昼夜循环全量（R10.2）、R10.3 回血、R5.6 视野阻挡、S3 暗夜夜间隐身特色、R8.4 野怪睡眠是否纳入本期属 **Q2 待拍板**——`WC3-MELEE-RULES.md:27`（S3）/ `:34`（§0）/ `:54`（§0.3 T2）字面「隐身 / 昼夜 / 暗夜特色随迷雾纳入一并做完」与 `P8-human-orc-melee.md:129` 本期验收线「最小闭环」存在**范围张力**，MUST 由用户拍板、不臆造、不静默窄化已拍板的 1.0 范围；若某项须进权威状态，按 `:131` 走 ADR 0002 全套（状态哈希 + 快照 + `first_difference()` + determinism 26 项 + bump + 重取 golden hash），与本期推荐方向冲突、须先拍板。
- **主 specs 口径：只修订承重 capability，其余登记已知限制（按 Q10 推荐，待规格门拍板）**：用 `## MODIFIED Requirements` delta 覆盖 `rts-command-hud` / `playable-client` / `3d-rendering` / `creep-camps` / `item-shop-town-portal` / `melee-match` 这 6 个承重 capability 中与迷雾可见性过滤 / 只读派生直接相关的 requirement；逐字保留全部历史 `#### Scenario:` 标题作身份键、口径写进 requirement 新正文与 THEN、MUST NOT 写 `## Purpose` 覆盖 delta；归档时才合并，本阶段不改主 `openspec/specs/**` 正文。其余主 specs 的历史硬禁令 / 「`SNAPSHOT_VERSION` 仍为 3」口径残留是否本 change 全量修订属 **Q10 待拍板项、不预设结论**（推荐沿 P8.5a–d 先例登记为已知限制、由 `docs-owner` 后续独立 change 统一收口）。
- **回归与门禁**：`cargo test -p w3-core --test determinism`（26 项）+「只读派生隔离回归」（`compute_state_hash()` / `capture_snapshot()` / `read_view()` 与无迷雾实例逐字节一致、`isolation.rs`、golden hash 不变、版本保持 7；Q9 形态①，退化实现真经生产路径注入，不冒充形态②）；`cargo test --workspace` / `cargo fmt --all -- --check` / `check_encoding.py` / `verify_all.py`（规格门 `status: pending` 期 fail-closed 为正确信号，不绕过、不改门禁）；联机两端 / 回放 / 重连一致性 CPU 回归；真窗口人工清单保持 `- [ ]`「未执行 / 待人工」、先离屏 `render_headless_rgba` + CPU 回归自证再请人工。
- **本阶段不改**：`crates/` 任何源码、`docs/references/WC3-MELEE-RULES.md` 活文档、ADR 正文、主 `openspec/specs/**` 正文、`openspec/config.yaml`、CI 配置；不 archive、不 commit、不 push / fetch / pull / clone。

## Capabilities

### New Capabilities

- `fog-of-war`: P8.5e 战争迷雾的表现层只读派生契约——三态迷雾网格与已探索层单调累积（R10.1）、当前可见每帧重算（R10.1）、视野范围与昼夜相位数据驱动（R10.1 / R5.6 / R10.2）、小地图单位点可见性过滤（R10.1 / T5）、敌方单位 / 建筑变化不可见（R10.1）、P8.5c / P8.5d 野怪 / 商店 / 地面物品可见性承接、`MUST NOT` 进权威状态 / 状态哈希 / 快照 / `first_difference()`（R10.5 / ADR 0002 §5）、版本保持 7 不 bump + golden hash 不变 + determinism 26 项不因迷雾改动、只读派生联机两端 / 回放一致（R12.2 / R12.4）、只读视图扩展边界、HUD 只读派生隔离、范围边界（隐身 / 昼夜 / 暗夜特色按 Q2 拍板）、零资产 / 许可证 / `[待核]`、真窗口人工清单保持未勾。

## Impact

- **代码面 / owner**：实施期 `client-owner` 为 `crates/w3-client/`（`hud.rs` 迷雾投影子模型 + `derive_minimap` 可见性过滤）与 `crates/w3-render/`（可选雾遮罩，只读、不反写）唯一实现所有者、主 owner；`docs-owner`（路线图 `:138` 版本沿革 / 主 specs delta 归档前复核）按 `CODEBUDDY.md §9` 由 leader 编排、串行协作、不并行改同一 owner 文件。**本期无 `w3-core` / `w3-net` / `w3-relay` 实现任务**（除非 Q1 拍板改内核，则须按 §8 同步修订四件套并重走规格门）；本提案阶段只写 `openspec/changes/p8-fog-of-war/` 下的文档，不改 `crates/` 任何文件。`w3-content` 原始 `f64` 冻结输入边界不变（ADR 0004）。
- **确定性契约（ADR 0002）**：推荐方向为**表现层只读派生、内核零权威状态改动**，不是 P8.5a–d 的「改内核新增权威状态 + bump + 重取 golden hash」型。迷雾网格 / 当前可见 / 已探索层 / 雾遮罩 MUST NOT 进 FNV-1a 状态哈希、由 `SNAPSHOT_VERSION`（当前 7）定义的快照、`first_difference()`；只读派生不改 `read_view()` / `drain_events()` / `compute_state_hash()` / `capture_snapshot()` 的字节。`SNAPSHOT_VERSION` / `SIM_VERSION` / `PROTOCOL_VERSION` 全部保持 7 不 bump、golden hash `0x940cb016f6630f1e` 不变；MUST 跑 `cargo test -p w3-core --test determinism`（26 项）证明「不因迷雾改动」，并按 `CODEBUDDY.md §5` / Q9 形态①做隔离回归反向验证（退化实现真经生产路径注入、不冒充形态②）。命令排序键、30 Hz 整数帧、稳定 `EntityId` 顺序、FNV-1a 编码方式不变；`w3-core` 仍不得依赖 `w3-content` / render / ui / audio / net。
- **联机 / 回放（R12.2 / R12.4 / ADR 0005 §4）**：只传玩家输入命令、MUST NOT 传迷雾状态 / 游戏状态；联机两端各自本地派生（纯函数 `f(同一权威状态序列, 本地视角, 冻结常量)`）、逐帧 checksum 比权威状态哈希不含迷雾 → 不引入新 desync 面；回放从录像重建同一命令序列 + 同一冻结常量 + 同一视角 → 同一迷雾，迷雾不进快照、重放按帧重新累积。**不 bump `PROTOCOL_VERSION`、不新增 proto tag、不改 `w3net.proto`**；`vera20k@305ea3a75 docs/Networking.md:281-284,486-490` 仅借「表现层不决定仿真顺序 / 逐帧 checksum 比权威状态哈希」语义，不借「每 House fog 在 shared world」。重连 / 中途加入 / 变速 / 多视角观战（R12.3 / R12.5 `[待核]`）的一致性契约属 Q7 待拍板项。
