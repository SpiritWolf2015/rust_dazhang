> **文档定位**：本文件是 `rust_dazhang` 项目**自己整理的 WC3 Melee 对战业务规则基线**，是玩法实现的**需求源**——subagent 写代码、`critic` 复核、单元测试与 OpenSpec Scenario MUST 引用本文的规则编号（`R-x.y`）。它是**活文档**：后续每做一个玩法，按 §14 补充或修订，并在文末登记变更。
>
> **不是上游参考项目**：四个只读开源参考项目的路径与许可证在 `UPSTREAM.md`；本文件是「游戏业务规则」，两者不互相替代。
>
> **合规边界（ADR 0001）**：本文只记录公开资料中可核对的**规则性事实**与本项目取舍，为原创中文整理，不复制百科 / 攻略原文，不含任何暴雪资产、图标、模型、音效或 MPQ 派生数据。具体数值（造价、生命、伤害、经验、时间、上限）一律**不锁定**：以玩家自备正版经典客户端经 `godot_warcraft3` 导出的本机 SLK 表为唯一数值来源，导出数据留在 gitignored 本机路径，不入库（ADR 0001 / ADR 0004）。
>
> **确定性边界（ADR 0002）**：本文规则若要进入权威状态，MUST 只经 `w3-core` 既有命令面实现；新增权威状态字段 MUST 同步进状态哈希、快照与 `first_difference()`，并保持 30 Hz 整数帧与命令稳定排序。
>
> **状态标记**：`[已核]` 多源公开资料一致的规则性事实；`[待核]` 需本机导出数据或原版客户端复核；`[取舍]` 本项目在 ADR 约束下的实现决定，不是原版事实，**不冒充经典规则**。

## 1. 实体分类与命令可移动性（`R1`）——**R1 是「金矿 / 主基地也会移动」bug 的根因章节，实现与单测 MUST 先读。**

### R1.1 实体分类 `[已核]`

经典 Melee 地图上可被框选 / 编队的实体至少分四类，**命令响应不同**：

| 类别 | 例子 | 归属 | 能否移动 | 能否被攻击 | 右键地面 |
|---|---|---|---|---|---|
| 可移动单位 | 工人、近战 / 远程 / 攻城 / 空军、英雄、召唤物 | 玩家 或 中立敌对 | **能** | 能 | 移动（`Move`） |
| 建筑 | 城镇大厅 / 主城、兵营、祭坛、人口建筑、防御塔 | 玩家 | **不能**（例外见 R1.2） | 能 | **不产生移动命令** |
| 资源点 | 金矿、树木 | 中立（非玩家单位） | **不能** | 树木可被攻城武器破坏；金矿不可 | **不产生移动命令** |
| 地面物品 | 野怪掉落宝物 | 无主 | 不能（被拾取） | 不能 | 英雄走过去拾取 |

### R1.2 建筑可移动性的例外 `[已核]`

- 绝大多数建筑**不可移动**。[已核]
- **暗夜精灵古树类建筑**可「拔根 / 扎根」，拔根后成为可移动单位（护甲类型也随之从城甲变重甲），可移动、可攻击；这是种族特色，不是通用建筑行为。[已核]
- 因此「建筑是否可移动」MUST 由**定义层数据**（`UnitDef` 的种族 / 建筑类别 / 可移动性字段）决定，**MUST NOT** 用「名字含 hall / mine / tree 的字符串」或硬编码白名单判断。[取舍]

### R1.3 右键「智能指令」分发 `[已核]`

右键单击在不同目标上触发不同动作（游民星空 / 新浪《基本操作与快捷键》双方一致）：

| 右键目标 | 动作 |
|---|---|
| 地面 / 小地图地面 | 移动单位到目的地（途中受攻击不还击） |
| 敌方单位 / 建筑 | 攻击目标（`Attack`） |
| 己方 / 友军单位 | 跟随 |
| **树木 / 金矿** | **可采集单位 → 采集该资源（`Gather`）；非采集单位 → 仅移动到其附近** |
| 地上宝物 | 英雄走过去拾起 |
| 正在指定法术目标时 | 取消命令 |

### R1.4 框选 / 编队与命令过滤 `[已核]` + `[取舍]`

- 左键拖拽框选可同时选中**单位与建筑**；选中一组后一次性下达指令；编队（Ctrl+数字）也可含建筑；Tab 在混编中切换同类型小组。框选与编队**允许建筑进入选中集合**，但命令分发 MUST 按目标类型过滤。[已核]
- **本 bug 的规则陈述**：一个「农民 + 主城 + 金矿」的混合选中集合对地面右键时，MUST **只为农民**生成 `Move` 命令；主城（建筑）与金矿（资源点）MUST NOT 生成 `Move`、MUST NOT 改变位置。[取舍，来自 2026-11-14 真窗口验收发现的已知限制，见归档 `2026-11-14-melee-playable-loop/design.md` Risks 末条]
- 实现要求：过滤 MUST 由**定义层可移动性数据**驱动，在**表现层输入翻译层**完成；MUST NOT 扩展 `WorldView` / `EntityView`，MUST NOT 用运行时 `speed`，MUST NOT 回退到类型白名单（`p8-faction-foundation` D1）。[取舍]
- 落点分配 MUST 按稳定 `EntityId` 顺序，且过滤后集合与「只含可移动单位」的落点逐条相同。[已核，参照 `rts_kernel_cs/docs/MOVEMENT.md:73-81`；具体由 `unit-orders` spec 约束]

### R1.5 采集规则 `[已核]`

- 黄金来自金矿，由工人采集送回城镇大厅（各族机制不同：人 / 兽工人往返；暗夜小精灵需先由生命之树缠绕金矿；不死族在金矿上建「被诅咒的金矿」由僧侣环绕获取）。[已核，数值 / 工人上限待核]
- 木材来自树木，可见树木均可伐；树木可倒下消失。[已核]
- 资源点（金矿 / 树木）是**中立、不可移动、非玩家单位**。[已核]

## 2. 四个种族（`R2`）

`[已核]` 四族：人族（Human / Alliance）、兽族（Orc / Horde）、不死族（Undead / Scourge）、暗夜精灵（Night Elf）。四族**单位 / 建筑 / 科技 / 基地建设方式互不相同**，不对称。

| 种族 | 机制要点 | 建筑 / 人口特点 | 英雄（原版 → TFT） |
|---|---|---|---|
| 人族 | 均衡、防御强、法师体系、民兵 | 农场供人口；箭塔；城镇大厅 | 大法师、山丘之王、圣骑士 → 血法师 |
| 兽族 | 重甲肉搏、正面强、萨满图腾 | 地洞兼人口与防御（苦工可钻入）；箭塔 | 先知、剑圣、牛头人酋长 → 暗影猎手 |
| 不死族 | 依赖尸体、食尸回血、召唤骷髅 | **建筑 MUST 建在腐蚀之地（blight）**；通灵塔供人口；金矿需诅咒金矿 | 死亡骑士、巫妖、恐惧魔王 → 地穴领主 |
| 暗夜精灵 | 机动 / 远程、古树建筑、夜间隐身 | **古树建筑可拔根移动**；月亮井回血回蓝；小精灵缠绕金矿 | 恶魔猎手、月之女祭司、丛林守护者 → 守望者 |

- 中立英雄（酒馆招募）：熊猫酒仙、娜迦女海巫、黑暗游侠、火焰领主、深渊领主、兽王、地精修补匠、炼金术士等。[已核]
- 每族特色单位（步兵 / 火枪 / 骑士 / 狮鹫 / 坦克；咕噜兵 / 狼骑 / 牛头人 / 飞龙；食尸鬼 / 蜘蛛 / 石像鬼 / 憎恶 / 冰龙；弓箭手 / 女猎手 / 德鲁伊 / 奇美拉）。[已核，具体数值 / 解锁条件待核]
- **数据口径**：四族定义全为合成 / 原创编译期整数常量（ADR 0001 零资产），数值以本机导出 SLK 为准、不入库、不进权威状态（ADR 0002 / ADR 0004）。[取舍]

## 3. 资源与人口（`R3`）

- **R3.1** 三种资源：黄金（Gold）、木材（Lumber）、人口 / 食物（Food / Supply）。前两者用于建造、训练、研究；人口限制同时存在的单位上限。[已核]
- **R3.2 维护费（Upkeep）**：单位人口超过阈值后，采金收益按比例下降（公开资料常见「低维护费 / 高维护费」两档）。阈值与倍率 `[待核]`，以本机导出常量为准；机制 MUST 进权威状态（若纳入 1.0）。[已核机制 / 待核数值]
- **R3.3 采集效率**：单个金矿有并行工人数上限（公开资料常见 5），超过不再提升效率；木材采集工人数因族而异。[待核数值]
- **R3.4 人口建筑**：各族有供人口建筑（人族农场、兽族地洞、不死族通灵塔、暗夜月亮井），部分有附加功能（地洞防御、月井恢复）。[已核]
- **R3.5 资源共享**：盟友间可通过联盟菜单共享资源（联机对战相关）。[已核；1.0 是否纳入待拍板]

## 4. 建筑与科技树（`R4`）

- **R4.1 城镇大厅 / 主基地**：可升级两次（T1 → T2 → T3），逐级解锁建筑与科技；是资源送回点；主基地被摧毁影响胜负判定（R11）。[已核]
- **R4.2 祭坛**：召唤与复活英雄。[已核]
- **R4.3 生产建筑**：普通 / 法术 / 种族特色（人族车间、兽族兽栏、不死族屠宰场、暗夜奇美拉栖木等）。[已核]
- **R4.4 研发建筑**：每族有攻 / 防升级建筑；其他强化多在该单位的生产建筑研究。[已核]
- **R4.5 防御建筑**：直接攻击敌对目标的塔类（各族不同）。[已核]
- **R4.6 建造约束**：不死族建筑须在腐蚀之地；放置需合法地形 / 占位校验。[已核 / 待核细节]

## 5. 单位与战斗（`R5`）

- **R5.1 攻击类型**：普通、穿刺、攻城、魔法（法术）、混乱、英雄。[已核]
- **R5.2 护甲类型**：无甲、轻甲、中甲、重甲、城甲（建筑）、英雄甲。[已核]
- **R5.3 克制矩阵**：穿刺克无甲 / 轻甲；攻城克城甲（建筑）；魔法克重甲；英雄攻击对英雄甲无减免；混乱攻击几乎不受减免。具体倍率 `[待核]`，以本机导出为准。[已核框架 / 待核数值]
- **R5.4 攻击方式**：溅射（炮火 / 箭矢，按距离衰减）、弹射（顺延攻击附近敌人，后续伤害递减）。[已核]
- **R5.5 地形**：高地对低地攻击有加成（3D 地形引入）。[已核；1.0 是否纳入待拍板]
- **R5.6 空中单位**：可穿越地形障碍、视野不受地形限制。[已核]

## 6. 英雄（`R6`）

- **R6.1 等级**：1–10 级；击杀敌方单位 / 野怪获得经验升级；每级学技能，6 级解锁大招。[已核；经验阈值待核]
- **R6.2 物品栏**：英雄 6 格，可携带 / 使用 / 丢弃 / 移交宝物。[已核]
- **R6.3 死亡与复活**：英雄阵亡不直接判负；可在本族祭坛复活（费用 / 时间随等级变化），或在酒馆「买活」中立 / 阵亡英雄（费用更高、复活时半血无蓝）。[已核 / 数值待核]
- **R6.4 属性**：力量 / 敏捷 / 智力，影响生命 / 护甲 / 法力。[已核]
- **R6.5 经验分配**：范围内英雄分摊经验；满级英雄是否参与分摊 `[待核]`。

## 7. 道具 / 物品（`R7`）— 1.0 范围 S4

- **R7.1 分类**：消耗品（药水、卷轴、召唤物、显影之尘、回城卷轴、传送权杖、重修之书等）、永久宝物（头环、护甲、靴子、光环类）、属性书（力量 / 敏捷 / 智力 / 全属性 / 生命上限 / 经验）。[已核]
- **R7.2 来源**：野怪掉落、商店 / 市场购买、地图预设。[已核]
- **R7.3 商店机制**：地精商店出售固定常用道具（随游戏时间逐步解锁）；市场道具随机刷新、有限库存、购买后冷却刷新。[已核 / 具体清单待核]
- **R7.4 售卖**：打野 / 购入的道具可售，但回购价显著低于购入价。[已核 / 数值待核]
- **R7.5 实例独立**：同名道具的多个实例 MUST 有独立状态（充能 / 冷却），不得共用（项目 `ItemInstance` 已约定）。[取舍]
- **R7.6 边界**：道具 abilList / 效果 MUST 走项目既有 `EffectDef` 组合，MUST NOT 直接执行任意 JASS 技能（ADR 0003 不做 JASS VM）。[取舍]

## 8. 野怪 / Creeps（`R8`）— 1.0 范围 S5

- **R8.1 定义**：对所有玩家敌对的中立单位，守卫金矿、中立建筑、关键路径。[已核]
- **R8.2 营地分级**：按强度常以颜色 / 等级区分（绿 < 黄 < 红），等级越高经验、金币、掉落越好。[已核 / 具体分级待核]
- **R8.3 击杀收益**：经验给附近英雄、金币、掉落物品（R7）。[已核]
- **R8.4 昼夜行为**：多数野怪夜间睡眠、不主动攻击；部分（石头人等）夜间清醒。[已核]
- **R8.5 行为**：有警戒 / 追击 / 归巢（leash）边界，MUST NOT 无限追出营地。[已核；AI 细节待核]
- **R8.6 掉落确定性**：掉落 MUST 由冻结随机码（种子随对局快照）决定，重放一致（ADR 0002）。[取舍]

## 9. 中立建筑（`R9`）— 1.0 范围 S6

`[已核]` 常见中立建筑及功能：

| 建筑 | 功能 |
|---|---|
| 酒馆 | 招募中立英雄；买活阵亡英雄；开局一段时间后才可用；需己方有祭坛 |
| 地精商店 | 出售常用道具（固定清单，随时间解锁） |
| 雇佣兵营地 | 招募中立战斗单位（通常低级近战 / 远程 / 辅助 / 重型各一） |
| 地精实验室 | 提供地精单位（炸弹人 / 伐木机器人 / 地精飞艇）与「真视」技能 |
| 市场 | 随机刷新道具商店 |
| 泉水 | 生命之泉 / 法力之泉，范围内自动恢复 |
| 巨龙栖地 | 招募大型龙类单位（大型特殊地图） |
| 地精船坞 | 提供运输船（水域地图） |
| 传送门 | 单位传送（特殊地图） |

- **R9.1** 中立建筑多为**不可移动、无主、可被交互**；部分装饰性建筑不可选定。[已核]
- **R9.2** 中立建筑周围常有野怪守卫（R8）。[已核]
- **R9.3** 交互（购买 / 招募 / 使用服务）走黄金（部分另需木材），MUST 经既有命令面与资源结算，不新增旁路写入。[取舍]

## 10. 视野 / 迷雾 / 昼夜（`R10`）— 与 ADR 0003 有张力，见 §0.3 T2

- **R10.1 迷雾**：地图初始不可见，探索后地形保留、但离开视野的区域被战争迷雾覆盖（敌方单位 / 建筑变化不可见）。[已核]
- **R10.2 昼夜循环**：白天 / 夜晚交替（公开资料常见各约 2 分钟）；影响视野范围、部分种族回血、暗夜隐身、野怪睡眠。[已核 / 时长待核]
- **R10.3 回血**：人族 / 兽族非机械单位昼夜均回血；暗夜单位仅夜间回血；英雄昼夜均自动回血。[已核]
- **R10.4 隐身**：部分暗夜单位夜间静止时隐身。[已核]
- **R10.5 边界（若纳入 1.0）**：迷雾 / 视野是**表现层只读派生**，MUST NOT 进权威状态 / 状态哈希 / 快照（ADR 0002）。[取舍]

## 11. 胜负与结束（`R11`）

- **R11.1 多人对战胜利条件**：**摧毁对手全部建筑**（`destroy all the buildings of the opposition`）。[已核，Wikipedia / Fandom 一致]
- **R11.2 英雄死亡不结束对局**：英雄可复活（R6.3）。[已核]
- **R11.3 认输 / 离开**：一方认输或离开判负；比赛规则另有限时与断线判定（如 60 分钟时限、断线按 replay 与积分裁决），属赛事规则非核心玩法。[已核 / 1.0 取舍待拍板]
- **R11.4 结算**：胜负只结算一次、按稳定顺序；结算帧与胜者进入权威状态（项目 `VictoryState::resolve_victory` 已实现）。[取舍]
- **R11.5 重开**：以相同冻结定义与开局脚本重新构造一局，不残留上一局权威状态（项目已实现 CPU 层）。[取舍]

## 12. 联机与回放（`R12`）— 1.0 范围 S1 / S2

- **R12.1 联机形态**：局域网（LAN）或平台联机；经典支持最多 12 名玩家分组；1.0 只做**局域网联机**，走自建 lobby / relay（ADR 0003 不与官方战网兼容）。[已核 / 本项目取舍]
- **R12.2 命令帧同步**：只传输玩家输入命令，MUST NOT 传输游戏状态；lockstep 逐帧 checksum 与 `first_difference()` 检测 desync（项目 `w3-net` / `w3-relay` 已交付）。[取舍 / ADR 0005]
- **R12.3 回放可录制与观看**：一局可存为录像、之后加载观看，支持变速与多视角。[已核]
- **R12.4 回放确定性**：录像 MUST 能逐帧重放且哈希与原局一致；回放数据 MUST 含冻结定义哈希 / 内容哈希 / 命令序列 / 帧号（ADR 0002 快照头部已有 `defs_hash` / `content_hash`）。[取舍]
- **R12.5 观战 / 断线重连**：公开资料提及 observers 与断线重连；1.0 是否纳入 `[待核 / 待拍板]`。
- **R12.6 录像存储**：录像文件 MUST NOT 含任何暴雪资产或导出数据；仓库不提交任何录像样本（ADR 0001）。[取舍]
